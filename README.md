# Claude Template

A starter template inspired by Claude Code.

[![Use this template](https://img.shields.io/badge/Use_this_template-181717?style=for-the-badge&logo=github)](https://github.com/new?template_name=pi-claude&template_owner=introspection-recipes)

## Quick Start

Create a repository with the button above, open it locally, then run:

```bash
pi install npm:@introspection-ai/recipes
cd your-repository
pi --recipe .
```

Set `PARALLEL_API_KEY` to enable web search.

## What's Included

- A lead agent with specialized subagents
- Claude-style planning, task, and interaction tools
- Review, security, simplify, run, and verification skills
